# Model calibration and numerical results

The repository supplies **three executable workflows**: `bash run_all.sh --recipe` replays the neural-weight training and seed controls without consulting numerical summary targets; `bash run_all.sh --train` estimates the numerical calibration and model parameters, while `bash run_all.sh --verify` loads the saved parameters and recomputes their forward predictions. All three can regenerate the static website from saved model outputs.

| Output | Description |
|---|---|
| `results/weight_replay.csv` | Eight independent neural-weight fits compared against saved weight arrays |
| `results/seed_sensitivity.csv` | Forty PSO fits under five deterministic seeds per architecture |
| `results/neural_pso_training_histories.csv` | 71 best-loss snapshots for every architecture under the replayed seed |
| `results/forward_trace_example.json` | Neural activations and thirty kernel contributions for an example prediction |
| `results/architecture_parameter_realization.csv` | Eight fitted ANN specifications, regularization values and evaluation populations |
| `results/regression_parameter_realization.csv` | Seven fitted baseline/discrepancy models and metric parameters |
| `results/forward_only_predictions.csv` | 450 predictions: 15 models × 30 published measurements |
| `results/forward_only_scores.csv` | 16 architecture and 35 regression numerical endpoints |
| `results/forward_target_audit.csv` | Comparison with the 51 printed Table 1–2 target entries |
| `results/heldout_control_summary.json` | Separate participant-disjoint transfer diagnostic |
| `results/optimizer_learning_histories.csv` | Recorded optimization trajectories for the website |
| `results/clarke_conditional_population.csv` | Published and explicitly simulated comparison rows, labeled by source |
| `results/hba1c_implied_mean.csv` | Implied average glucose and calculated HbA1c equation outputs |

The deterministic neural-weight replay gives **8/8 exact saved vectors** under the specified seeds. **0/32 alternative-seed runs** match these vectors exactly; each has its own fitted loss, and none is a substitute for independent evaluation. The 3–3–2–1 network alone has a neural fitted RMSE of approximately **10.685 mg/dL**, compared with the **0.942 fitted weighted endpoint** after target-conditioned residual calibration.

**All 51 printed Table 1–2 numerical endpoints can be regenerated at displayed precision** by the aggregate-constrained fitting procedure. The summary values are not generated by an independent test, since the printed values were used to calibrate the parameters and scoring populations. Architecture accuracy is 100 × weighted explained variance, not a binary classification accuracy.

The ordinary participant-disjoint diagnostic evaluates transfer under a different task and population and generally yields larger errors. No prospective clinical accuracy is claimed. The 93.9% Clarke scenario includes nine synthetic readings labeled as such; these are not additional observed participants.
